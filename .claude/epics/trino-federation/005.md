# Task: Scan path — splits and streaming page source

## Description

Make `SELECT` work end to end. `FederationSplitManager` emits one `FederationSplit(regionName)`
per active region in the table handle. `FederationPageSourceProvider` builds the regional SQL via
`RemoteSqlBuilder`, executes it through `RegionClient`, and streams rows into pages. The `_region`
column is materialized as a per-split constant block when projected.

## Acceptance Criteria

- [ ] `SELECT * FROM federation.s.t` returns the UNION ALL of all regions (embedded-region test)
- [ ] Splits are `remotelyAccessible`, no host affinity; regions stream concurrently when the
      engine schedules multiple splits
- [ ] Page source respects projected column subset (only those columns in regional SELECT list)
- [ ] `_region` selectable alone and with other columns; correct value per region
- [ ] Cancellation/close aborts the remote regional query (verify via client state)
- [ ] Completed bytes/positions metrics reported

## Technical Details

- Page source pulls a batch of rows per `getNextPage` into `PageBuilder` (target ~1MB/page),
  lazy blocking is fine (`isBlocked` optional in v1 — synchronous reads acceptable).
- Empty projection (e.g. `count(*)` fallback path) → `SELECT 1 AS dummy` or count query per page
  source contract: emit pages with correct positionCount and zero channels.
