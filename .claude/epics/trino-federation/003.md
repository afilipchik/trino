# Task: RemoteSqlBuilder — regional SQL generation

## Description

Pure-function SQL generator for the queries sent to regions. Given table name, projected columns,
`TupleDomain` constraint, optional limit, optional TopN (sort items), and optional aggregation
spec (grouping columns + rewritten aggregate expressions), produce the regional SQL text.
Trino-to-Trino, so standard Trino syntax — no dialect layer.

## Acceptance Criteria

- [ ] Identifier quoting (`"…"` with embedded-quote doubling) for catalog/schema/table/columns
- [ ] Literal rendering for every type task 002 maps: correct escaping for varchar, `X'…'` for
      varbinary, `DATE '…'`/`TIMESTAMP '…'` forms, exact decimal text, special double values
      (infinity/NaN excluded from pushdown instead of mis-rendered)
- [ ] `TupleDomain` → WHERE: ranges, IN-lists, IS NULL / IS NOT NULL, none/all handling;
      non-representable domains omitted (caller keeps them as post-filter)
- [ ] LIMIT and ORDER BY … LIMIT (TopN) clauses with NULLS FIRST/LAST and asc/desc
- [ ] Aggregate SELECT list generation: `count(*)`, `count(x)`, `sum(x)`, `min(x)`, `max(x)`,
      and avg decomposition (`sum(x)` + `count(x)`) with GROUP BY
- [ ] Exhaustive unit tests (no server needed) — golden SQL strings

## Technical Details

- Input is connector-domain objects (column handles carry remote names + types), output is a
  `String` plus the ordered result column descriptors the page source should expect.
- Keep it side-effect free for easy testing; this task owns no SPI code.
