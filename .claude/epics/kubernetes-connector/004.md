# Task: Discovery and OpenAPI-to-Trino type mapping

## Description
Resource discovery (`/api/v1`, `/apis` aggregated discovery → groups,
preferred versions, resources with list+get verbs, namespaced flag) and
OpenAPI v3 (`/openapi/v3/<group path>`) JSON-schema → Trino type mapper:
object→ROW (preserve field name case), additionalProperties→MAP,
array→ARRAY, string(date-time)→TIMESTAMP_TZ_MILLIS, int32→INTEGER,
int64→BIGINT, number→DOUBLE, boolean→BOOLEAN, int-or-string→VARCHAR,
$ref resolution with cycle detection → JSON fallback, empty/unknown → JSON.
Caching (Guava, TTL from config).
